## Git কী?

Git হলো একটি ডিস্ট্রিবিউটেড ভার্সন কন্ট্রোল সিস্টেম। এটি ডেভেলপারদের কোডের পরিবর্তন ট্র্যাক করতে এবং একাধিক ব্যক্তির মধ্যে সহযোগিতা করতে সাহায্য করে।

Git 2005 সালে লিনাস টরভাল্ডস তৈরি করেছিলেন এবং আজ এটি বিশ্বের সবচেয়ে জনপ্রিয় ভার্সন কন্ট্রোল সিস্টেম।

## কেন Git ব্যবহার করবেন?

### ভার্সন হিস্ট্রি

Git প্রতিটি পরিবর্তনের একটি রেকর্ড রাখে। আপনি যেকোনো সময় পূর্ববর্তী ভার্সনে ফিরে যেতে পারেন।

### ব্রাঞ্চিং

Git-এ ব্রাঞ্চ তৈরি করে আলাদাভাবে কাজ করা সহজ। পরে `main` ব্রাঞ্চে মার্জ করা যায়।

### সহযোগিতা

GitHub, GitLab ইত্যাদি প্ল্যাটফর্মের মাধ্যমে দলের সদস্যরা একসাথে কাজ করতে পারে।

## বেসিক Git কমান্ড

### সেটআপ

```bash
git config --global user.name "আপনার নাম"
git config --global user.email "your@email.com"
```

### রিপোজিটরি তৈরি

```bash
git init                  # নতুন রিপো তৈরি
git clone <url>           # বিদ্যমান রিপো ক্লোন
```

### কমিট প্রক্রিয়া

```bash
git add .                 # সব ফাইল স্টেজ করুন
git commit -m "বার্তা"    # কমিট করুন
git push                  # রিমোটে পাঠান
git pull                  # রিমোট থেকে আনুন
```

### ব্রাঞ্চ

```bash
git branch feature-x      # নতুন ব্রাঞ্চ
git checkout feature-x    # ব্রাঞ্চে যান
git merge feature-x       # ব্রাঞ্চ মার্জ
```

## সারমর্ম

Git শেখা প্রতিটি ডেভেলপারের জন্য অপরিহার্য। ভার্সন কন্ট্রোল না জানলে আপনি বড় প্রজেক্টে কাজ করতে পারবেন না। আজই Git শুরু করুন!
