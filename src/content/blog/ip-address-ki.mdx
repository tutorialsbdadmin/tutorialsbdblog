## IP Address কী?

IP Address (Internet Protocol Address) হলো একটি ইউনিক নম্বর যা ইন্টারনেটে বা নেটওয়ার্কে প্রতিটি ডিভাইসকে চেনার জন্য ব্যবহৃত হয়। ঠিক যেমন আপনার বাসার একটি ঠিকানা আছে, তেমনি প্রতিটি ডিভাইসের একটি IP Address থাকে।

## IP Address কত ধরনের?

### IPv4 (Internet Protocol Version 4)

IPv4 হলো সবচেয়ে পুরোনো এবং সবচেয়ে বেশি ব্যবহৃত IP সংস্করণ। এটি 32-বিট এড্রেস ব্যবহার করে।

একটি IPv4 Address এর ফরম্যাট:

```
192.168.1.1
```

প্রতিটি অংশ (octet) 0 থেকে 255 পর্যন্ত হতে পারে।

### IPv6 (Internet Protocol Version 6)

IPv4 এর জন্য যথেষ্ট এড্রেস না থাকায় IPv6 তৈরি করা হয়েছে। এটি 128-বিট এড্রেস ব্যবহার করে।

IPv6 Address এর ফরম্যাট:

```
2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

## IP Address ক্লাস

| ক্লাস | রেঞ্জ | ব্যবহার |
|-------|--------|---------|
| A | 1.0.0.0 - 126.255.255.255 | বড় নেটওয়ার্ক |
| B | 128.0.0.0 - 191.255.255.255 | মাঝারি নেটওয়ার্ক |
| C | 192.0.0.0 - 223.255.255.255 | ছোট নেটওয়ার্ক |

## প্রাইভেট IP vs পাবলিক IP

### প্রাইভেট IP

আপনার লোকাল নেটওয়ার্কের ভেতরে ব্যবহৃত IP। রাউটার দ্বারা বরাদ্দ করা হয়।

```bash
# Windows এ IP দেখুন
ipconfig

# Linux এ IP দেখুন
ip addr show
```

### পাবলিক IP

ইন্টারনেটে আপনার ডিভাইসের ঠিকানা। ISP দ্বারা বরাদ্দ করা হয়।

## সারমর্ম

IP Address হলো নেটওয়ার্কিং-এর মৌলিক ভিত্তি। IPv4 এবং IPv6 এর পার্থক্য, IP ক্লাস এবং প্রাইভেট/পাবলিক IP বোঝা প্রতিটি নেটওয়ার্কিং শিক্ষার্থীর জন্য অত্যন্ত গুরুত্বপূর্ণ।
