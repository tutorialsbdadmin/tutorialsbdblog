## Linux কী?

Linux হলো একটি ওপেন-সোর্স, ইউনিক্স-ভিত্তিক অপারেটিং সিস্টেম। এটি 1991 সালে লিনাস টরভাল্ডস তৈরি করেছিলেন। আজ Linux বিশ্বের বেশিরভাগ সার্ভার, সুপারকম্পিউটার এবং এমনকি আপনার স্মার্টফোনে (Android) ব্যবহৃত হচ্ছে।

## কেন Linux ব্যবহার করবেন?

### নিরাপত্তা

Linux অন্যান্য অপারেটিং সিস্টেমের তুলনায় বেশি নিরাপদ। এটি ওপেন-সোর্স হওয়ায় হাজার হাজার ডেভেলপার নিয়মিত নিরাপত্তা আপডেট প্রদান করে।

### বিনামূল্যে

Linux সম্পূর্ণ বিনামূল্যে। Ubuntu, Fedora, Debian — এসব ডিস্ট্রিবিউশন বিনামূল্যে পাওয়া যায়।

### পারফরম্যান্স

Linux হালকা এবং দ্রুত। পুরোনো হার্ডওয়্যারেও Linux ভালো পারফর্ম করে।

## বেসিক Linux কমান্ড

### ফাইল নেভিগেশন

```bash
ls          # ফোল্ডারের ভিতরের ফাইল দেখুন
cd          # ডিরেক্টরি পরিবর্তন করুন
pwd         # বর্তমান পাথ দেখুন
```

### ফাইল ম্যানেজমেন্ট

```bash
touch file.txt     # নতুন ফাইল তৈরি
cp file.txt copy.txt    # ফাইল কপি
mv file.txt /path/      # ফাইল মুভ
rm file.txt             # ফাইল ডিলিট
```

### পারমিশন

```bash
chmod 755 file.sh    # পারমিশন পরিবর্তন
chown user:group file.txt    # মালিকানা পরিবর্তন
```

## Linux ডিস্ট্রিবিউশন

বিভিন্ন প্রয়োজনের জন্য বিভিন্ন ডিস্ট্রিবিউশন রয়েছে:

- **Ubuntu**: বেগিনারদের জন্য সেরা
- **Fedora**: ডেভেলপারদের জন্য জনপ্রিয়
- **CentOS/RHEL**: সার্ভারের জন্য আদর্শ
- **Arch Linux**: অ্যাডভান্সড ব্যবহারকারীদের জন্য

## সারমর্ম

Linux শেখা আজকের IT পেশাদারদের জন্য অত্যন্ত গুরুত্বপূর্ণ। এটি নিরাপদ, দ্রুত এবং বিনামূল্যে — এবং সার্ভার অ্যাডমিনিস্ট্রেশন থেকে শুরু করে সাইবার সিকিউরিটি পর্যন্ত প্রতিটি ক্ষেত্রে এর ব্যবহার রয়েছে।
