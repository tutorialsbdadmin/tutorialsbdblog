## Firewall কী?

Firewall হলো একটি নেটওয়ার্ক সিকিউরিটি ডিভাইস বা সফটওয়্যার যা ইনকামিং এবং আউটগোয়িং নেটওয়ার্ক ট্রাফিককে নির্ধারিত নিয়ম অনুযায়ী ফিল্টার করে। এটি আপনার নেটওয়ার্ককে অননুমোদিত অ্যাক্সেস থেকে রক্ষা করে।

## Firewall কত ধরনের?

### স্টেটফুল ইন্সপেকশন ফায়ারওয়াল

সকল সক্রিয় কানেকশনের ট্র্যাক রাখে। সবচেয়ে সাধারণ এবং কার্যকর প্রকার।

### প্যাকেট ফিল্টারিং

প্রতিটি প্যাকেটের IP এড্রেস এবং পোর্ট নম্বর চেক করে।

### প্রক্সি ফায়ারওয়াল

ক্লায়েন্ট এবং সার্ভারের মধ্যে মধ্যস্বত্বভোগী হিসেবে কাজ করে।

### Next-Generation Firewall (NGFW)

ঐতিহ্যবাহী ফায়ারওয়ালের সাথে DPI (Deep Packet Inspection), IPS এবং অ্যাপ্লিকেশন কন্ট্রোল যুক্ত থাকে।

## ফায়ারওয়াল কীভাবে কাজ করে?

### ইনবাউন্ড রুল

ইনকামিং ট্রাফিক কোন পোর্ট বা IP থেকে আসতে পারে তা নির্ধারণ করে।

### আউটবাউন্ড রুল

আউটগোয়িং ট্রাফিক কোথায় যেতে পারে তা নির্ধারণ করে।

### ডিফল্ট পলিসি

সাধারণত `deny all` — অর্থাৎ, নির্দিষ্টভাবে অনুমোদন না করা সব ট্রাফিক ব্লক করা হয়।

## Linux তে ফায়ারওয়াল

```bash
# UFW (Uncomplicated Firewall)
sudo ufw enable              # চালু করুন
sudo ufw allow 22/tcp        # SSH অনুমোদন
sudo ufw allow 80/tcp        # HTTP অনুমোদন
sudo ufw allow 443/tcp       # HTTPS অনুমোদন
sudo ufw status              # অবস্থা দেখুন
```

## সারমর্ম

Firewall হলো নেটওয়ার্ক সিকিউরিটির প্রথম এবং সবচেয়ে গুরুত্বপূর্ণ স্তর। সঠিকভাবে কনফিগার করা ফায়ারওয়াল আপনার নেটওয়ার্ককে বেশিরভাগ আক্রমণ থেকে রক্ষা করতে পারে।
